# Regression & t-Test Lab

## Run locally
1. Install Python 3.10 or newer.
2. Open a terminal in this folder.
3. Run: `pip install -r requirements.txt`
4. Run: `streamlit run app.py`

## Deploy on Streamlit Community Cloud
1. Upload `app.py` and `requirements.txt` to a GitHub repository.
2. In Streamlit Community Cloud, create an app and select `app.py` as the main file.
3. Deploy.

## Modules
- Multiple linear regression with two or three predictors
- One-sample t-test
- Independent two-sample t-test (Welch or pooled Student)
- Paired t-test
- Editable tables and CSV upload
- Step-by-step statistics, formulas, decisions and interpretations

Note: The app uses standard OLS regression inference and conventional t-tests. Check assumptions before drawing real-world conclusions.
